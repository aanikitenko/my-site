## Что такое Markdown?

Markdown — это лёгкий язык разметки для форматирования текста.

## Основной синтаксис

# Заголовок 1
## Заголовок 2
### Заголовок 3

- Элемент списка
- Ещё элемент

**Жирный текст**

*Курсив*

## Где используется

- GitHub
- Hugo
- Telegram
